# 时迹 · 时间账本

一个单机就能跑的个人时间分配记录页面：给每一类时间设目标、开倒计时/正计时、写完事之后回填"刚才干了什么"，每天自动换一条关于时间的名言和一幅插画。

打开方式：直接访问 `index.html`（无需服务器、无需安装、无任何外部依赖）。

## 功能

- **六类默认时间**：课本知识学习 / 阅读书籍 / 运动 / 信息获取 / 课题推进 / AI学习，可自行增删、改色、改每日目标
- **倒计时 & 正计时**：到设定时长自动结束；中途关闭页面会保存，重新打开可续算（离开超过 90 秒会问你要不要补时）
- **每类可写日记**：每天每类时间下面记录"这段时间干什么了"，按天归档
- **每日名言 + 插画**：48 条中英文名言轮换，引文可用楷体/隶书/行楷切换；插画是程序生成的 SVG，不联网、无版权问题
- **统计**：最近七天堆叠柱状图、每类周合计、今日完成度
- **数据自主**：导出/导入 JSON、导出 CSV，全部存在浏览器 localStorage，不上传任何服务器

## 数据说明

数据只存在**当前浏览器**的 localStorage（键名 `shiji.ledger.v1`）。换浏览器、换设备、清缓存都会看不到旧数据 —— 想迁移就用「数据」按钮里的导出，再在新设备导入（导入会覆盖当前全部数据）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式（含深色主题、响应式、打印样式） |
| `app.js` | 全部逻辑：状态、计时、渲染、导入导出 |

本地预览服务器 `serve.cjs`（可选，仅开发用）不在本目录内，也不需要。
