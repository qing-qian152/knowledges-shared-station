# 知识共享站 · knowledges-shared-station

一个仓库装两个互不相干的小项目，共同点是：**纯前端、零构建、零后端、零账号**。
双击 `index.html` 就能跑，推上去就能看。

线上：<https://qing-qian152.github.io/knowledges-shared-station/>

| 项目 | 位置 | 一句话 |
| --- | --- | --- |
| **每日一学 · Daily Learn** | 仓库根目录 | 每天一页：晨读 / 古诗文 / 英文精读 / 英语听力，配今日一句与任务清单 |

## 每日一学 · Daily Learn

每天一期，四个板块：

| 板块 | 内容 |
| --- | --- |
| **晨读** | 一篇完整的名篇（原创 1300–1700 字，或逐字照录的公版经典）+ 应景插画 + 逐句讲解 + 好词好句 + 写作手法 + 当天能写完的仿写任务 |
| **古诗文** | 一首与当日主题呼应的诗词：插画、注释、白话译文、结构赏析、背诵提示 |
| **英文精读** | 480–600 词原创文章（IELTS 7.0 难度）+ 逐段译文开关 + 生词、地道搭配、短语、句式、语法点 + 中文摘要 + 5–6 道单选 + 输出任务 |
| **英语听力** | 180–260 词原创英文短文，页面内用浏览器语音合成逐句朗读（三种风格、多音色、按标点切短句留气口）+ 高亮跟读 + 原文/译文切换，不依赖任何外链 |
| **今日清单** | 可勾选任务，勾选即存，全部勾完提示休息 |

互动：答错自动进错题本（带中文解析）、生词卡点击显隐、英文全文朗读、笔记自动保存、板块完成标记、每日打卡与连续天数、深浅色切换、按日期回看历史。

### 这个站刻意做成这样

- **零依赖、零构建**：原生 HTML/CSS/JS，没有 npm，没有 bundler。数据用 `<script>` 注入 `window.LEARN_DAY` 而不是 `fetch` JSON，所以 `file://` 双击不会被 CORS 拦。
- **零后端、成本与访客数无关**：没有服务器、数据库、账号。一天只在写作时花一次模型调用。
- **进度本地化**：答题、错题本、打卡、笔记全在 `localStorage`，不上传任何数据；可导出/导入 JSON 搬家。
- **读得完**：单日正文铺开原本要滚 30 屏，二次阅读材料收进 `<details>` 抽屉（开合状态记在本机），内容一字不删，整页压到约 14 屏。
- **能换样**：6 套配色 + 5 种中文字体 + 3 种英文字体 + 3 档字号，右上角 ◐ 切换，选择记在本机；首次访问跟随系统深浅色。
- **能当 App**：`manifest.json` + Service Worker，安装到桌面后全屏、断网可看读过的内容。
- **能被搜到**：每期一个 `?d=日期` 真链接，`sitemap.xml` + `robots.txt` + 页脚往期链接 + JSON-LD，标题描述按当天内容动态更新。
- **能存档**：页脚一键把整年导出成一个自带样式的离线 HTML。

### 本地打开

```bash
# 方式一：直接双击 index.html（不需要任何配置）
# 方式二：起个静态服务器，验证 PWA / 离线缓存 / ?d= 深链
node scripts/dev-server.mjs          # → http://127.0.0.1:8123/
```

### 每天的内容是怎么来的

一期内容 = 四个板块的 JSON，合成一个 `data/days/YYYY-MM-DD.js`。
写作与发布由 `scripts/daytool.py` 管（纯标准库，**不需要 Node，也不需要 API Key**）：

```bash
python scripts/daytool.py new     --date 2026-11-23   # 建骨架 + 当日写作规格
python scripts/daytool.py build   --date 2026-11-23   # 合并分段稿 + 结构校验
python scripts/daytool.py publish --date 2026-11-23   # 重建索引 / sitemap / 往期链接
```

写作细节、字数、禁止事项见 [AGENTS.md](AGENTS.md) 与 [docs/内容规范.md](docs/内容规范.md)。

日常产出由每天 06:30 的定时任务按同一套流程执行，机制见 [docs/部署.md](docs/部署.md#每天-0630-的自动发布)。

> **这个仓库已经没有任何「调模型 API 自动生成内容」的代码了。**
> 早期（2026-10-26 至 11-15）走的是「GitHub Actions 定时调 API 生成 → 提交」的路子，
> 2026-11-22 整条链路连同脚本、主题池、workflow 与相关 Secret 一并移除，
> 现在内容只由 agent 按 `AGENTS.md` 写、由 `daytool.py` 校验发布。

### 提交前跑一遍

本地和 CI 用同一套命令，四个都过再推：

```bash
node scripts/check-structure.mjs      # 清单是否漂移（插图名、日期索引、sw 缓存、HTML 引用）
node scripts/check-themes.mjs         # 6 套主题的配色/插图变量是否齐全
python scripts/daytool.py check --all # 每一期内容过校验器
python scripts/daytool.py site        # 生成物与 data/ 同步（不该产生 diff）
```

`.github/workflows/verify.yml` 在每次 push / PR 时自动跑这四项，外加 JS 与 Python 的语法检查。

## 时迹 · 时间账本（`time-ledger/`）

独立的单页应用，跟站点其他部分没有依赖关系。打开 `time-ledger/index.html` 即用。

- **六类默认时间**：课本知识学习 / 阅读书籍 / 运动 / 信息获取 / 课题推进 / AI 学习，可增删、改色、改每日目标
- **倒计时 & 正计时**：到设定时长自动结束；中途关页面会保存，重开可续算（离开超过 90 秒会问要不要补时）
- **每类可写日记**：按天归档，"这段时间干了什么"
- **每日名言 + 插画**：48 条中英文名言轮换，引文可用楷体/隶书/行楷；插画是程序生成的 SVG，不联网
- **统计**：最近七天堆叠柱状图、每类周合计、今日完成度
- **数据自主**：`localStorage` 键 `shiji.ledger.v1`，可导出/导入 JSON、导出 CSV

数据只存在当前浏览器。换设备前先用「数据」里的导出，否则旧记录留在旧设备上。
详见 [`time-ledger/README.md`](time-ledger/README.md)。

## 内容来源与版权

- **语文**：原创（署「本站原创」），或逐字照录的公版名篇（作者去世 50 年以上，`chinese.origin` 标 `"public"`）
- **古诗文**：公版
- **英文精读 / 听力**：原创，不搬运他人文章；听力由浏览器语音合成朗读，不涉及第三方音频
- **网络字体**：`assets/fonts/` 下四份中文字体子集为思源宋体、文鼎 PL 楷、朱雀仿宋、霞鹜文楷，均为 OFL / Arphic 授权，已按本站用字子集化
- **配图**：`assets/art.js` 用代码画的水墨插画，无第三方素材

模型生成内容可能有事实或表述错误，尤其古诗文注释与语法讲解，请以自己的判断为准；发现问题欢迎提 Issue 或 PR。
