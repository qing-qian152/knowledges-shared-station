# 内容规范

写一期内容之前先看这页。规则不是"建议"——`scripts/daytool.py check` 会拦，`verify.yml` 会在 CI 里再拦一次。

---

## 一期内容的边界

一期 = 一个 `data/days/YYYY-MM-DD.js`，五个部分：`quote`（今日一句）、`chinese`、`poem`、`english`、`listening`，外加 `checklist`。

**不要一次写完一整期**（约 3.4 万字，必崩）。按板块分文件写，写完一块立刻校验：

```bash
python scripts/daytool.py new   --date 2026-11-23   # 生成 parts/2026-11-23/ 与写作规格
python scripts/daytool.py build --date 2026-11-23   # 合并分段稿 → data/days/2026-11-23.js
python scripts/daytool.py check --date 2026-11-23   # 单独复检（--fix 自动修可修的项）
python scripts/daytool.py publish --date 2026-11-23 # 重建索引 + sitemap + 往期链接
```

---

## 各板块规格

| 板块 | 硬要求 | 建议 |
| --- | --- | --- |
| **晨读** `chinese` | 原创 **≥1000 字**（低于 1000 直接报错）；`imitation.prompt` 必须有 | 1300–1700 字、7–9 段；讲解 4–5 条、好词 6–8、好句 3–4、手法 4–5 |
| **古诗文** `poem` | 整首（词要整阕，不许摘句）；注释、译文、赏析齐全 | 注释 4–6、赏析 3–4 段、有背诵提示 |
| **英文精读** `english` | `translation` 段数**必须与 `body` 完全相同**并逐段对应；`questions[].answer` 0 起始 | 480–600 词、5–6 段、IELTS 6.5–7.5；生词 12–15、搭配 8–10、短语 6–8、句式 4–5、语法 3–4；单选 5–6 题 |
| **英语听力** `listening` | 自创英文短文，`lines` 里 `en`/`cn` 一一对应；**不许任何外部链接** | 180–260 词，拆 6–10 句；标准美式拼写 |
| **清单** `checklist` | 覆盖四个板块，动词开头 | 5–6 项，每项配一句方法提示 `tip` |
| **今日一句** `quote` | 作者、出处 `source` 要有 | 优先可考经典；拿不准就换一句家喻户晓的 |

## `chinese.origin`：决定"能不能署真名"

这是最容易搞错、也最容易闯祸的一个字段。

| 取值 | 含义 | 署名要求 | 篇幅要求 |
| --- | --- | --- | --- |
| `"public"` | **逐字照录**公版原文（作者去世 50 年以上） | 可以写真名，如「朱自清」 | 整篇照录；低于 600 字判为截断（报错） |
| `"original"` 或缺省 | 本站原创 | 必须写「本站原创」 | ≥1000 字（1000–1300 警告，1300–1900 最佳） |

校验器以前的判断是"署了名家名就是伪造"，结果把《匆匆》《秋夜》这类**真正的**公版名篇也判成了伪造。
现在改成看 `origin`：

- 写名家名但没标 `"public"` → **报错**（这是伪造）
- 标了 `"public"` 但正文其实是仿写 → 校验器看不出来，只能靠写的人诚实
- 标了 `"public"` 却署名一个不是名家的名字 → 警告，确认没标错

> 站点上现存的公版篇目：`2026-10-26` 朱自清《匆匆》、`10-27` 朱自清《荷塘月色》、
> `10-30` 郁达夫《故都的秋》、`10-31` 鲁迅《秋夜》、`11-01` 老舍《济南的冬天》、
> `11-02` 胡适《差不多先生传》。它们都标了 `origin: "public"`。
> 另有一篇 `10-28`「做人与做事」原是仿《傅雷家书》的家书体原创，曾误署「傅雷」，已改正为「本站原创」。

## 四条禁止

1. **不许给原创文字署真名家名**。朱自清、鲁迅、郁达夫、老舍、傅雷、胡适、徐志摩、梁实秋、冰心、沈从文、汪曾祺、史铁生……名单在 `daytool.py` 的 `FAMOUS` 里。原创就写「本站原创」。
2. **不许编造名言或张冠李戴**。拿不准出处就换一句家喻户晓的，`source` 写空字符串。
3. **不许写外链**（听力尤其）。所有内容都要能离线读。
4. **不许动外壳**。`assets/`、`index.html` 的骨架、`sw.js`、`manifest.json` 除非用户明确要求改版式；真改了必须把 `sw.js` 的 `VERSION` 加一。

## 插图白名单

`image` 只能取这些场景名（`art.js` 里的键，也是 `daytool.py` 的 `ART` 列表）：

```
lotus-moon  autumn-mountain  bamboo       snow-peak    snow-boat
spring-river rain-window     dunes        border       pastoral
tower       plum             autumn-river pine-valley  lamp
paper       desk             bloom
```

写错不会报错到页面上——会静默退回素纸 `paper`（但 `check` 会先拦一次）。
`image` 可以不写，这时 `app.js` 按「日期 + 板块」稳定挑一张。

## 选题

不再有主题池文件（原来那份已随接口生成链路一起删除）。选题按三条判断：

1. **不重复**：主题与诗词都要避开最近 5 期（校验器会拦「近 4 期重复的诗词」，主题由写的人自己把关）。
   动笔前先看 `data/days/index.js` 里最近几天的 `theme`，以及最近几期的 `poem.title`。
2. **顺季节**：内容跟当时的时令走（入冬、初雪、年前的忙、春节前的空），读者在现实里能对上。
3. **有连线**：连续几天可以是一条线而非四个孤立的主题。例如 2026-11-16 至 11-22 那条：

   | 日期 | 主题 | 这条线上的位置 |
   | --- | --- | --- |
   | 11-16 | 入冬，学着把手脚放慢 | 慢下来（起点） |
   | 11-17 | 冬夜长，正好说完一句话 | 慢下来之后，开始说话 |
   | 11-18 | 把一件小事做完整 | 说的话变成做的事 |
   | 11-19 | 早市上的算术 | 做事的人与他的账 |
   | 11-20 | 有人替你醒着 | 从市井看到夜里的人 |
   | 11-21 | 把一天空出来 | 收束：空与不空 |
   | 11-22 | 临水而居，向水而思 | 换气，开下一条线 |

   不必每天都硬凑在一条线上，但要能说出「为什么是今天这一篇」。

四个板块之间不必同一题材，但**应当互相呼应**：语文写「等」，古文最好是写等的；英文与听力可以同一主题域，
用不同角度（一个议论、一个叙事）。

## 校验器都在看什么

| 检查 | 级别 |
| --- | --- |
| 日期/星期与文件名不符 | 报错（`--fix` 可修） |
| 晨读原创 <1000 字 / 公版 <600 字 | 报错 |
| 晨读署名家名但没标 `origin: "public"` | 报错 |
| `chinese.origin` 不是 `public` / `original` | 报错 |
| `english.translation` 段数与 `body` 不符 | 报错（`--fix` 按正文补齐） |
| 单选题 `answer` 越界 | 报错 |
| 听力缺译文 | 报错 |
| `image` 不在白名单 | 报错（`--fix` 退回 `paper`） |
| 字体/字号变量散落 | 不查（那是 `check-themes.mjs` 的事） |
| 晨读 1000–1300 字 / 偏长 / 段数不在 7–9 | 警告 |
| 好词、好句、讲解数量偏少 | 警告 |

全部日期一次过筛（CI 用的就是它，只读、不改）：

```bash
python scripts/daytool.py check --all
```
